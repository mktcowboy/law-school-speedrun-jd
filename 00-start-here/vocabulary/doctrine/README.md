## How These Relate To The Cross-Cutting Files

A subject file gives a term its doctrinal treatment; the cross-cutting files give the shared vocabulary. A term like `respondeat superior` is defined once as Latin in [latin-and-foreign-phrases](../latin-and-foreign-phrases.md) and referenced from [torts](./torts.md) and [business associations](./business-associations.md); `res judicata` is Latin but gets its procedural detail in [civil procedure](./civil-procedure.md). Follow the `related:` links to move between them.
